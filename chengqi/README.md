# 成器 · 景泰蓝师徒解谜

> 玉不琢，不成器。

一款等距视角的视错觉解谜网页游戏，以《拾月》demo 为技术底座，题材是国家级非物质文化遗产「景泰蓝制作技艺」（铜胎掐丝珐琅）。
老师傅带着徒弟阿蓝，走完寻矿、制胎、掐丝、点蓝、烧蓝、磨光、镀金，把天上那件空着的梅瓶，一道工序一道工序地做成。

## 怎么玩
- 打开 `index.html`（或单文件版 `成器.html`），iPad 和电脑都可以玩，不需要联网。
- **轻点地面**：让人物走过去。看起来相连的地方，就走得过去（视错觉）。
- **拖动金珠**：转动铜胎、升降铜台、掐转金丝。
- **轻点丝格**：丝格合拢后，轻点灌釉。没合拢时，釉会从缺口漏下去。
- **来回划动**：在灰黑的氧化渣上来回划，把它磨亮。
- **轻点人物**：双人关里切换阿蓝和师傅，也可以用顶部按钮或 Tab 键。
- 快捷键：R 重来本章，M 静音。URL 加 `?lv=0`～`?lv=7` 可以直达某一幕。

## 核心设定：天上的器
每一幕的终点是一扇金色的门，门里浮着这道工序的**信物**：色样、铜胎、金丝、釉、火、光、金，最后是一件器。
阿蓝取到信物后，它会飞向画面右侧那件梅瓶。梅瓶的变化如下：

| 完成的工序 | 梅瓶的样子 |
|---|---|
| 开始 | 一圈金色虚线，器还是空的 |
| 寻矿 | 蓝矿色样在瓶旁浮着 |
| 制胎 | 出现铜胎 |
| 掐丝 | 胎上出现金丝纹样（如意云头、缠枝、莲瓣） |
| 点蓝 | 丝格里填上釉 |
| 烧蓝 | 釉色变得饱满 |
| 磨光 | 瓶身出现高光 |
| 镀金 | 金丝变亮 |
| 复磨 | 器成，发光 |

它的作用相当于《纪念碑谷》里归还的神圣几何、《拾月》里拾回的月光：玩家一眼就知道自己在做什么、做到了哪一步。
阿蓝腰间的七格丝格也会随章节一格格点上不同的釉色。

## 每一幕的工艺逻辑（去掉景泰蓝，这一关就不成立）
| 幕 | 工序 | 机关 | 工艺对应 |
|---|---|---|---|
| 序 | 寻矿 | 踩矿脉升起石路，拖动铜台 | 釉料来自矿石，先要找到颜色 |
| 一 | 制胎 | 转动铜胎转盘 + 视错觉连通 | 铜片锤打成胎，器有了骨 |
| 二 | 掐丝 | 掐转两根金丝，让丝格合拢后才能灌釉；旧纹样谱是一条死路 | 丝合拢的格子才盛得住釉 |
| 三 | 点蓝 | 一根金丝围出两个丝格：先点一格，转丝，再点另一格 | 相邻丝格共用一根丝；一色一格 |
| 四 | 烧蓝 | 双人操控：师傅踩住窑口托起丝桥，来路被窑火吞没，阿蓝独自过桥 | 烧蓝要有人守火；师徒分别 |
| 五 | 磨光 | 来回划动磨去氧化渣，露出镜面釉 | 砂石、黄石、木炭逐层打磨 |
| 六 | 镀金 | 两人在不同高度，屏幕上光晕重叠处金箔凝成路，一前一后交替前进 | 隔着山水，金线相连 |
| 七 | 复磨 | 师傅为阿蓝托住路，两人并肩站到重燃的窑前 | 窑火重燃，一脉接续 |

每一关都由求解器验证过：`node tools/solve.js`，检查可解、无死局、无重叠、角色脚下始终有效。
还用求解器给出的解在真实游戏里自动通关过一遍。

## 美术
- **材质**：古铜（锤纹和铜绿）是实体可走的；金丝是镂空骨架，不可走；珐琅釉是半透明的宝石面，可走。门是极简的长方形金框，不用圆拱，也不用船舵式转轮。
- **色彩体系**：景泰蓝不只有蓝色。釉色取真实的珐琅色谱：松石绿、珊瑚红、明黄、青金蓝、翠绿、粉、乳白。
- **天色**：延续《纪念碑谷》的柔和治愈感，每一幕一个时辰：
  - 寻矿：薰衣草色的黎明
  - 制胎：杏色的晨光，有天窗光束
  - 掐丝：青瓷绿
  - 点蓝：松石与珊瑚
  - 烧蓝：落日珊瑚红
  - 磨光：银灰色的雾晨
  - 镀金：紫色的黄昏星空
  - 复磨：金粉色的日出
- **光照**：主光加实时投影，金属边缘有高光，釉面有菲涅耳反光。阿蓝手里的釉灯、窑火和金门都是点光源。机关落定后先闪一下光，停半拍，人再走。
- **人物（原创设计）**：
  - 阿蓝：青金色长衫，腰间一圈七格丝格，提一盏小釉灯。
  - 老师傅：编钟般外扩的深褐长袍，铜绿围裙，金丝圆镜，背着掐丝的长镊子，身形微驼。
- **背景**：水彩晕染、矿物颗粒、铜锈暖褐，远山山脊勾一笔哑金细线。

## 声音（全部由代码实时合成）
- 乐器：编钟（非谐分音）、磬、古琴（拨弦合成，带吟猱滑音与泛音）、箫、埙、笙、堂鼓。
- 每一幕一段五声小曲，按「A A B A」反复：

  | 幕 | 调式 | 配器 |
  |---|---|---|
  | 序 | 羽调 | 埙与风声 |
  | 制胎 | 宫调 | 编钟与錾铜声 |
  | 掐丝 | 徵调 | 古琴 |
  | 点蓝 | 宫调 | 上行琴音 |
  | 烧蓝 | 羽调 | 心跳般的堂鼓与笙 |
  | 磨光 | 商调 | 独奏古琴 |
  | 镀金 | 羽调 | 箫与埙一问一答 |
  | 复磨 | 宫调 | 全编制 |

- 音效按材质区分：铜面闷响、釉面清脆、金箔细亮。踏步音也落在当前调式里。打磨声越磨越亮；灌釉是一串上行的水泡音；漏釉是一串下行的滴答。

## 文件
```
index.html        入口
js/levels.js      八幕关卡数据（几何、机关、色板、文案）
js/logic.js       世界模型、视错觉连通、寻路、灌釉/磨光/托举/双晕规则
js/gfx.js         WebGL 渲染器（材质、阴影贴图、点光源）
js/audio.js       程序化音乐与音效（也可离线渲染）
js/game.js        主循环、建模、交互、演出、界面
tools/solve.js    关卡求解器
```

## 史实
- 景泰蓝制作技艺于 2006 年列入第一批国家级非物质文化遗产名录。
- 景泰蓝在明代景泰年间技艺成熟，因而得名。
- 1951 年，梁思成、林徽因在清华大学营建系组织抢救小组，请回了改行多年的老艺人。
