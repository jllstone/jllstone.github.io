# 成器 · 景泰蓝师徒解谜（Demo 第三版）

> 玉不琢，不成器。

一款等距视角的视错觉解谜网页游戏，题材是国家级非物质文化遗产「景泰蓝制作技艺」（铜胎掐丝珐琅）。
窑火将熄的年月，老师傅带着徒弟阿蓝，俯身走进一只还空着的铜胎，走完七道工序。器成了，人也成了。

## 怎么玩
- 打开 `index.html`（或单文件版 `成器.html`），手机、iPad、电脑都能玩，不需要联网。
- **轻点地面**：人物走过去。看起来相连的地方，就走得过去（视错觉）。
- **拖动金珠**：转动铜胎、升降铜台、转动或沿轨道滑动金丝。
- **轻点丝格**：丝格合拢后，轻点灌釉。金丝一离开，这一格的釉就散回空框。
- **来回划动**：在灰黑的氧化渣上来回划，把它磨亮。
- **左下角头像**：双人关里切换阿蓝和师傅，也可以直接点人物，或按 Tab。
- 开场轻触案头的铜胎，「成器」二字会被金丝掐出来；再轻触，就俯身入器。章节卡出现时轻触可提前进入。
- 右上角三个图标依次是选章、重来本章（R）、声音（M）。URL 加 `?lv=0`～`?lv=7` 可以直达某一幕。

## 第三版改了什么

### 一、带入与转场：照着《纪念碑谷3》重做
逐帧拆了 MV3 的实机录屏和 PV，抓住四件事：
- 世界自己开场，不放标题页；
- 引导藏在场景里；
- 过关有一个「归还」的仪式；
- 章节之间是一条连续的镜头，中间不黑场。

据此，入器、引导、过关、转场全部重做：

| MV3 的做法 | 《成器》第三版 |
|---|---|
| 没有标题页，标题从世界里长出来 | 暗夜作坊里只有一只铜胎和一圈呼吸的光环。轻触后，金屑从器口升起，按掐丝→点蓝→烧蓝→磨光→镀金的顺序，把「成器」二字“做”出来 |
| 镜头钻进物件，进入关卡 | 再轻触，镜头沉入器口，直接落到第一章 |
| 沙漏形章节卡：两块色面对合，中间是章名 | 每章一组配色的上下三角色面，中间是竖排、景泰蓝工艺写成的章名和一句心境 |
| 关卡从线稿“搭”出来 | 章节卡滑开后，关卡先由金丝勾出线框，再由下而上填成实体 |
| 引导：光圈提示 + 场景里的对白 | 对白直接出现在场景里，每章一两句师徒对话；闲置时，可点的地方浮出呼吸光圈：可灌釉的丝格、该拖的金珠、该划的氧化渣、该站的炉砖 |
| 过关时归还神圣几何，天色流转 | 光柱升起，本章的器纹用金丝在空中描出来，天色随之流转，最后化作一粒光，落进背景瓶影的那一圈 |
| 画面缩进一个窗口，下一关在窗里出现 | 整个画面缩进一只梅瓶形的窗；窗里先浮出下一章的金线框，再填上颜色；最后菱形色块一层层推开，下一章的章节卡就位 |

### 二、反馈修复
1. **师徒同格**：两人不再停在同一格。师傅跟随时会自动让到旁边空着的格子；实在无处可让，就和阿蓝换位。万一重叠，渲染上也会各自错开半身。
2. **手机上点不上蓝**：
   - 丝格的点击判定扩大到至少约 30 像素，并且优先于地面；
   - 金珠的判定半径至少 32 像素；
   - 人物的判定半径至少 26 像素；
   - 可灌釉的丝格会浮出蓝色光圈，提示可以点。
3. **烧蓝**：
   - 左侧升降台加了两根金色导轨和横档，从远处也看得出能升降；
   - 侧视改为偏正面的 3/4 视角；
   - 上下两层的路改成不同高度，不再并排；
   - 规则改为按人判定：阿蓝上了升降台、且师傅在窑房时，来路才塌落，避免两人互相锁死。
4. **成器终章**：不用实拍图。一是版权，二是画风会断。改为一只程序绘制的景泰蓝梅瓶：
   - 瓶身有缠枝莲、如意云头、莲瓣和回纹，纹样贴在圆柱展开面上，会随瓶身缓缓转动；
   - 按制胎→掐丝→点蓝→烧蓝→磨光→镀金依次长成，底下一排工序字随之点亮。
5. **字与器的遮挡**：手机竖屏时，瓶在上、工序在中、「成器」在下；横屏与电脑上，瓶在左，「成器」竖排在右。两种布局都检查过，互不遮挡。
6. **「成器」二字**：
   - 字形用马善政毛笔楷书（SIL OFL 开源字体，只取用到的十几个字的轮廓，内嵌为路径）；
   - 字的呈现就是一遍景泰蓝工艺：金丝沿笔画勾边，釉色填进字腔（里面还有小团花和卷草），入窑泛红，磨光时一道高光扫过，最后镀金。
7. **角色**：
   - 阿蓝：斗笠、靛蓝长衫、米白前襟、金色下摆、珊瑚色腰带，提灯挂在手上；
   - 师傅：钟形长袍、铜绿围裙、黑帽、长须、眼镜、手里拿镊子，双手背在身后；
   - 两人都有了手臂和走路时的摆动。

### 三、新 PV（76 秒，1080p）
节奏参照 MV3 的 PV，全片无旁白、无字幕卡，剪辑点都落在 90 拍/分的拍点上：
1. 一镜入器：开场→成器→入器→章节卡→线框组装→对白；
2. 快剪：制胎、掐丝、磨光；
3. 点蓝收官→归还器纹→缩进梅瓶窗→第四道 · 烧蓝；
4. 烧蓝：来路塌落，镜头转为侧面，阿蓝独自上升；
5. 窗中小景：月洞、海棠、梅瓶、菱花四种窗形，每窗两拍；
6. 镀金：隔山相望；复磨：重逢，窑火重燃；
7. 终章：梅瓶成器，「成器」二字以掐丝珐琅写出。

配乐是另写的一份宫调总谱（烧蓝一段转羽调），和游戏音效一起离线合成。

## 第二版改了什么（对应《第二轮优化调整方案》）

### 1. 器即空间（删掉了右上角的 2D 花瓶）
- **开场俯身入器**（约 3.5 秒，可点击跳过）：暗夜作坊的案头上，静置着一只暗哑的空铜胎。镜头推近，顺着器口沉进去，豁然展开成等距舞台。
- **方案 C · 水雾暗纹**：一只巨大的淡墨瓶影藏在背景水雾里，平时几乎看不见。完成一道工序的瞬间（灌釉、磨光、托举、踩亮矿脉），瓶影上对应的那一圈像宣纸吸墨一样亮起，随后沉回去。过关时，信物也飞进这一圈。
- **方案 A · 负空间瓶影**（烧蓝）：最后一段丝桥接通的一瞬，两座高塔之间的留白被金丝弧线围成一只瓶，亮半拍后淡去。
- **方案 B · 七关合器**（终章，第三版已改为梅瓶成器）：「器，成了。」之后镜头拉远、缓缓旋转，七层分别对应七道工序，从雾里一层层升起、叠合成一只完整的大器：
  - 石座嵌矿
  - 铜胎
  - 镂空金丝笼
  - 松石釉
  - 窑火青金
  - 宝石蓝
  - 金口

### 2. 真解谜：有限金丝与互相让位
| 幕 | 机关 | 要想清楚的事 |
|---|---|---|
| 二 掐丝 | 只有一根沿轨滑动的金丝，一次只合得住一格。金丝走开，身后那格的釉就散回空框；有人站在格上时，金丝不能动 | 踩完尽头的机关后要折返：得先把金丝推回中间那格、重新灌釉，才回得去 |
| 三 点蓝 | 一根金丝绕着中庭转，三格丝格轮流合拢 | 先走右边踩亮机关，再折回中庭换左边 |
| 四 烧蓝 | 两人一到窑前，来路就塌进火里，镜头转成正面剖面：下层窑房里师傅守火，上层冷光里阿蓝独行。师傅站到哪块炉砖上，那一段路就被金丝吊起来 | 师傅要在下层一格格挪，为阿蓝搭路；他自己上不去 |
| 六 镀金 | 两条金路隔着夜色：师傅踩住金砖，阿蓝的路才亮；师傅自己往前的路，得等阿蓝去踩亮 | 交替搭台，一前一后地让路 |

每一关都由求解器验证过：`node tools/solve.js`，检查以下几项：
- 可解；
- 无死局；
- 可走砖不重叠；
- 人物脚下的砖始终有效；
- 摆件不压在可走的格子上。

还用求解器给出的解，在真实游戏里自动通关过一遍。

### 3. 视角突变
烧蓝一幕里，相机从 45° 等距视角平滑转为正面剖面，转完后照常点击操作。

### 4. 情绪弧线与美术
- **前段，克制微光**：
  - 序：靛蓝黎明
  - 制胎：暗作坊里的冷天窗
  - 掐丝：深青
  - 点蓝：冷月
- **中段，暗场与围困**：
  - 烧蓝：八成炭青暗场，左下是窑火的暖光，右上是冷白硬光
  - 磨光：反「浮空塔」的下沉深井，四壁冷灰，亲手磨亮的台阶透出宝石蓝和细锐的金丝边
  - 镀金：夜色
- **终章，窑火重燃**：金粉色的日出。
- **其他**：
  - 背景加了一层宣纸纤维和矿物颗粒；
  - 移除了制胎墙面上的绿色小方窗；
  - 釉色仍然取景泰蓝的真实色谱：松石绿、珊瑚红、明黄、青金、宝石蓝、粉。

### 5. 去科普味
- 章节页和过关文案只写师徒的心境，例如「空着的地方，才好落第一笔」「他没跟来，火还在烧」。
- 工艺说明句全部去掉。
- 史实与申遗年份退为终章右下角的淡色角标。

### 6. 手机端修复
- 右上角的「章 / 复 / 音」改为图标按钮。
- 「阿蓝 / 师傅」改为左下角的头像按钮，不再和标题、按钮重叠。
- 所有摆件都挪离了可走的格子，人物不会再穿过窑、铁砧、半成的铜胎等摆件。求解器里加了检查，以后不会复发。
