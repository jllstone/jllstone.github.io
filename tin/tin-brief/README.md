# 《铁皮的旅行》画师需求说明

给画师看的需求文档：画什么、画成什么样、怎么算合格，含对错示例、8 张每页任务单和验收标准。

## 打开方式

- **直接双击 `index.html`** 即可，不需要服务器。
- **`画师需求说明.pdf`** 是同样内容的 PDF，方便用微信或邮件发给画师。
- 也可以放到任意静态网站服务器上。

## 和另外两个包一起部署

页面顶部的“打开占位版”“画稿自检页”两个按钮，指向同级目录的 `../tin-book/index.html` 和 `../tin-check/index.html`。三个文件夹放在同一个网站目录下就能直接跳转：

```
网站根目录/
├─ tin-book/
├─ tin-check/
└─ tin-brief/   （本包）
```

如果部署在不同的地址，用文本编辑器打开 `index.html`，搜索 `../tin-book/index.html` 和 `../tin-check/index.html`，改成实际网址即可。

## 修改内容

- 文字直接改 `index.html`。
- 图片在 `img/`：`s1–s8` 是占位版截图，`g1–g8` 是地面页底稿，`dd-*` 是对错示例，`tin-*` 是角色分件示例，`chk_*` 是自检页截图。
- 改完想更新 PDF：用 Chrome 打开 `index.html`，按 Ctrl/Cmd+P，选“另存为 PDF”，勾选“背景图形”。
