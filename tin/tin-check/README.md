# 《铁皮的旅行》画稿自检

画师把导出的 PNG 拖进来，页面会逐项检查并标红或标绿，说明哪里要改：

- **角色分件**：画布是否一样大、部件是否齐全、背景是否透明、每个关节和身体有没有重叠（转动会不会露缝）、有没有单独的眼睛层；角色会直接动起来给你看。
- **立牌和道具**：背景透明、边缘干净、一张图只有一样东西、底边能不能站稳、尺寸、文件名是否在任务单里。
- **地面页**：尺寸 2048×1200、整页铺满、网格线是否删干净，并可以和底稿叠在一起对位置。

所有检查都在画师自己的浏览器里完成，图片不会上传。

## 打开方式

- **直接双击 `index.html`** 就能用，不需要服务器，也不需要联网。
- 也可以双击 `启动-Mac.command` / `启动-Windows.bat`，或把整个文件夹放到任意静态网站服务器上。

## 目录

```
index.html      全部页面和检查逻辑（单个文件）
ground/         8 张地面页底稿缩略图（ch1.jpg … ch8.jpg），用于“地面页”标签里的叠图对位
```

## 修改

- **任务清单**：`index.html` 里搜索 `const TASKS =`，每一项是 `{"s":跨页,"f":"文件路径","n":"名称","c":"类型","h":高度}`。增删立牌时同步修改，“文件名在不在任务单里”的检查就以它为准。
- **角色必需的部件**：搜索 `const NEED =`。
- **底稿**：替换 `ground/chN.jpg` 即可。
- **判断阈值**：关节重叠的标准在 `ratio < 0.06`（重叠深度小于部件长度的 6% 判为露缝）；半透明杂边的标准在 `0.18`。
